Variable: ${{ s.variable }} — 1 when the client is in the list, otherwise 0. WafControl declares it automatically in /etc/nginx/conf.d/wafcontrol-geo-<name>.conf using nginx's built-in geo module (fast even for large countries); you only add the if line.

{% if action != 'allow' %}
Deny geo list — block these countries
server {
    listen 80;
    server_name example.com;

    if (${{ s.variable }}) { return 403; }
    ...
}
{% endif %} {% if action != 'deny' %}
Allow geo list — only these countries can access
location /admin/ {
    if (${{ s.variable }} = 0) { return 403; }

    proxy_pass http://127.0.0.1:8080;
}
{% endif %}

Put the line in server to protect a whole site, or in a location for a path. if (...) { return 403; } is the safe way to use if in nginx. Several lists can be combined with several if lines.

Behind a proxy/CDN, configure set_real_ip_from / real_ip_header so nginx sees the real client IP.

{% elif s.key == 'nginx' %}

Include file: {{ s.path }}

{% if action != 'deny' %}
Allow list — only these IPs can access

Add the include line, then deny all; right after it. Nginx checks rules in order and stops at the first match, so the include must come before deny all;. Works inside http, server or location.

location /admin/ {
    include {{ s.path }};
    deny all;

    proxy_pass http://127.0.0.1:8080;
}
{% endif %} {% if action != 'allow' %}
Deny list — block these IPs, allow everyone else

Add only the include line; everyone not in the list is allowed. Put it in server to protect a whole site, or in a location for a path.

server {
    listen 80;
    server_name example.com;

    include {{ s.path }};
    ...
}
{% endif %} {% if not action %}
Both together

Deny list first, then allow list, then deny all;.

include /etc/nginx/wafcontrol/iplists/blocked.conf;
include /etc/nginx/wafcontrol/iplists/office.conf;
deny all;
{% endif %}

Note: return runs before allow/deny checks, so a location that only does return ...; is not protected. Use it with proxy_pass, root or try_files.

Behind a proxy/CDN, configure set_real_ip_from / real_ip_header so nginx sees the real client IP.

{% else %}

Include file: {{ s.path }}

{% if kind == 'geo' %}

Apache has no built-in country matching, so WafControl expands the countries into their IP ranges inside this file. It is used exactly like an IP list. Large countries produce many ranges that Apache checks one by one; prefer nginx for big geo lists.

{% endif %} {% if action != 'deny' %}
Allow list — only these {% if kind == 'geo' %}countries{% else %}IPs{% endif %} can access

Wrap the Include line in <RequireAny>. Anyone not matching is refused (403). Works inside <VirtualHost>, <Directory> or <Location>.

<Location "/admin/">
    <RequireAny>
        Include {{ s.path }}
    </RequireAny>
</Location>
{% endif %} {% if action != 'allow' %}
Deny list — block these {% if kind == 'geo' %}countries{% else %}IPs{% endif %}, allow everyone else

Require not ip only works inside <RequireAll> together with Require all granted.

<Location "/">
    <RequireAll>
        Require all granted
        Include {{ s.path }}
    </RequireAll>
</Location>
{% endif %} {% if not action and kind != 'geo' %}
Both together
<RequireAll>
    Include /etc/apache2/wafcontrol/iplists/blocked.conf
    <RequireAny>
        Include /etc/apache2/wafcontrol/iplists/office.conf
    </RequireAny>
</RequireAll>
{% endif %}

Behind a proxy/CDN, enable mod_remoteip so Apache sees the real client IP.
