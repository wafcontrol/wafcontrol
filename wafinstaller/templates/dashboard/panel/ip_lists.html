How to use a list

  1. Create a list: an IP list (addresses / CIDR ranges) or a Geo list (countries, from the bundled GeoLite2 database), and choose Allow (only these may access) or Deny (block these).
  2. WafControl generates the files for every installed web server, tests the config and reloads it.
  3. Add the line once to the site config where it should apply (examples below and on each list's page). Later edits of the list apply automatically.
