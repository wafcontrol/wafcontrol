What is sent

WAF attacks — every new attack detected: IP, country, host, URI, rule ID, message, severity and anomaly score. Severity is mapped to syslog levels (Info → info, Low → notice, Medium → warning, High → err).

User actions — login, logout, failed login / 2FA, and every change made in the panel (who, from which IP, what action, submitted fields). Passwords, OTP codes and file contents are never sent.

Messages are JSON in the syslog message body, tagged with the app name.
